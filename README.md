# frossta's neovim configuration

## Keymaps
`map leader = ' '`
### Normal Mode
| Command      | Description                |
| ------------ | -------------------------- |
| `<leader>pv` | open netrw                 |
| `<C-n>`      | toggle neotree on the left |
| `<leader>ff` | fuzzy finder               |
| `<leader>fg` | live grep                  |
| `K`          | hover                      |
| `gd`         | go to definition           |
| `<leader>ca` | code action                |
